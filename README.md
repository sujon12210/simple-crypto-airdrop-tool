# Simple Crypto Airdrop Tool

This project sends tokens to many wallets.
It works on Ethereum testnet.
You can learn how airdrops work.

This project is made for beginners.
All code is simple and clear.

## Features
- Send tokens to many wallets
- Load wallet list from file
- Command line tool
- Simple config file

## Requirements
- Node.js installed
- Testnet wallet
- ERC20 token contract
- RPC provider account

## Setup
1. Clone this repo
2. Open folder in terminal
3. Run: npm install
4. Create a file called .env
5. Add private key and RPC URL
6. Run: node airdrop.js

## Example
Put wallet addresses in wallets.txt
Run the script.
Tokens will be sent.

## Learning Goals
- Learn airdrop logic
- Learn token transfers
- Learn blockchain loops
